# Space Battle

## Description
Space Battle est un petit jeu développé en Python où deux vaisseaux s'affrontent dans l'espace. 
Les joueurs peuvent déplacer leurs vaisseaux et tirer pour toucher l’adversaire. 
Le jeu inclut la gestion des collisions, la logique de mouvement et des interactions simples.

## Technologies utilisées
- Python
- Pygame
- Programmation orientée objet

## Objectif du projet
- Pratiquer la programmation Python et la logique de jeu
- Développer une interface interactive et responsive
- Appliquer les concepts de la programmation orientée objet

## Comment jouer
1. Installer Python et Pygame
2. Lancer le fichier `main.py`
3. Utiliser les touches définies pour déplacer les vaisseaux et tirer
4. Le jeu se termine lorsque l’un des vaisseaux est touché
